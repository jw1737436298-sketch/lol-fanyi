# LOL 小悬浮翻译器

这是一个 Windows 小弹窗工具，不是网页。

它会置顶显示在 LOL 上方，不注入游戏进程，不修改游戏文件。

## 功能

- 复制英文/德文聊天后，一键翻译成中文
- 输入中文后，一键翻译成自然游戏英语
- 中文转英文后自动复制，回 LOL 里直接粘贴发送
- 小窗口置顶，可隐藏/显示

## 使用

1. 复制 `.env.example` 为 `.env`
2. 在 `.env` 里填入 `OPENAI_API_KEY`
3. 双击 `start_lol_translator.bat`

## 快捷键

- `Ctrl + Alt + T`：显示/隐藏窗口
- `Ctrl + Alt + C`：翻译剪贴板成中文
- `Ctrl + Alt + E`：把输入框中文翻译成英文并复制

如果快捷键被 LOL 或其他软件占用，可以直接点按钮使用。
